# StickMultiKit

[简体中文](#简体中文) | [English](#english)

## 简体中文

StickMultiKit 是一个基于 EEex 的 Infinity Engine 增强版游戏模组，让兼职角色可以拥有并正确应用多个职业宗派。

### 要求

- EEex
- StickLuaFunctions `v0.8.1-Alpha`

### 收录版本

本仓库仅收录 `0.3.x` 系列：

- `StickMultiKit_v0.3.0-Alpha`
- `StickMultiKit_v0.3.1-Alpha`

### 安装

1. 安装所需版本的 EEex 和 StickLuaFunctions。
2. 将所需 StickMultiKit 版本目录中的文件复制到游戏根目录。
3. 运行 `Setup-StickMultiKit.exe`。
4. 按照 WeiDU 安装程序的提示完成安装。

## English

StickMultiKit is an EEex-based mod for Infinity Engine Enhanced Edition games. It allows multiclass characters to use multiple kits and correctly applies their features.

### Requirements

- EEex
- StickLuaFunctions `v0.8.1-Alpha`

### Included Versions

This repository includes only the `0.3.x` series:

- `StickMultiKit_v0.3.0-Alpha`
- `StickMultiKit_v0.3.1-Alpha`

### Installation

1. Install the required versions of EEex and StickLuaFunctions.
2. Copy the contents of the desired StickMultiKit version directory into the game root directory.
3. Run `Setup-StickMultiKit.exe`.
4. Follow the prompts in the WeiDU installer.
